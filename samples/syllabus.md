# Python 入门到 AI 小项目（8 周课程）

> 面向零基础大学生。目标：从"会写几行代码"到"独立做一个带记忆的 AI 小 Agent"。
> 教学方式：ILT（讲师引导式培训）+ 每周末交付一个可运行小作品。

## 课程目标
- 掌握 Python 基础语法与文件读写
- 理解"大模型本身无记忆，记忆靠外部文件"这一关键认知
- 能独立跑通一个本地/云端调用的最小 Agent
- 学会用 GitHub 把自己的作品开源出去

## Week 1: 环境与第一行代码
### 学习目标
- 能在自己电脑跑通 Python
- 理解变量、输入输出、报错怎么读
### 核心内容
- 安装 Python 与编辑器
- print / input / 变量
- 如何读懂报错信息

## Week 2: 用程序处理文字与文件
### 学习目标
- 会读写本地文本文件
- 理解字符串与列表的基本操作
### 核心内容
- open() 读写文件
- 字符串拼接、切分
- 第一个小工具：记事本

## Week 3: 数据结构入门
### 学习目标
- 理解字典 dict 并能存/取键值
- 理解 JSON 是"给程序看的字典"
### 核心内容
- dict 的增删改查
- json.dumps / json.loads
- 把一组笔记存成 memory.json

## Week 4: 什么是"记忆 Agent"
### 学习目标
- 说清大模型为什么本身没有记忆
- 画出"读记忆→提问→写记忆"的循环
### 核心内容
- 上下文窗口概念
- memory.json 读写时机
- 半自动工具调用思路

## Week 5: 调用一个大模型
### 学习目标
- 能通过 API 或本地模型拿到一句回答
- 理解 prompt 是怎么写的
### 核心内容
- 一次最小请求
- system / user 角色
- 常见报错与超时处理

## Week 6: 把聊天串成循环
### 学习目标
- 做出一个能多轮对话的命令行程序
- 把 memory 接进对话循环
### 核心内容
- while 循环读输入
- 每轮注入历史记忆
- 对话结束写回文件

## Week 7: 加一个技能（工具调用）
### 学习目标
- 实现一个关键词触发的小工具
- 理解"半自动调用"比"全自动"更适合新手
### 核心内容
- 关键词路由
- 技能函数的输入输出约定
- 错误兜底

## Week 8: 开源你的作品
### 学习目标
- 把代码整理成别人能用的样子
- 写 README 并发布到 GitHub
### 核心内容
- 目录结构与 README
- 通过接口上传文件
- 写一篇复盘文章
